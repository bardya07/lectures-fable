# Lectures Fable

Lectures Fable is a macOS app for organizing lectures, assignments, and exams by class.

## Install

Download the zip from [Releases](https://github.com/bardya07/lectures-fable/releases), unzip it, and move Lectures Fable.app to Applications. The app is not notarized, so the first time you open it, right-click the app and choose Open, or use System Settings → Privacy & Security → Open Anyway.

## Build from source

Run `./build.sh` on macOS. The app will be in `build/`.

## Data

Data is stored in `~/Library/Application Support/Lectures Fable/`. Use Export and Import to back up and restore it.
